## Current cross-domain clusters

### Compute
HBM → packaging → interconnect → thermal → power.

### Industrial autonomy
Measurement → semantics → digital twin → state estimation → control → qualification.

### Biology
Molecular design → cell/strain → bioreactor → separation → quality → manufacturing.

### Critical materials
Extraction → separation → refining → metallization/alloy → component → recycling.

### Space/autonomy
Sensing → timing/PNT → state estimation → navigation → communications → swarm control.

### Water/resources
Transport → membrane → selective separation → fouling control → resource recovery.

## Strategic interpretation
The strongest universal enablers are those that reduce the cost of crossing between physical states, scales, or information representations.
