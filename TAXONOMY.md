# Technology Foresight Taxonomy

## A. Discovery categories

### Frontier
New capabilities approaching useful deployment.

### Hidden enablers
Small or obscure components/processes that unlock larger systems.

### Bottlenecks
Constraints that limit scale, cost, reliability, or deployment of another technology.

### Reactivated legacy
Older technologies whose system value rises because surrounding conditions changed.

### Convergence
Capabilities created by combining previously separate domains.

### Infrastructure
Technologies required for persistent operation at system scale.

### Obsolescence / substitution
Technologies likely to lose importance because a new system architecture removes their role.

## E. Forecast windows

- `2026-2028`: near-term transition and scale bottlenecks.
- `2029-2031`: system integration and infrastructure formation.
- `2032-2034`: higher-uncertainty transformative capabilities.

The repository's primary horizon is 2026-2032; 2033-2034 is retained as an extension for technologies whose development cycles exceed six years.
